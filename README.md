# Suzi — my personal AI assistant

**Suzy** is a desktop voice AI assistant for Windows 10/11.

All code lives in the [`suzy/`](suzy/) folder. See [`suzy/README.md`](suzy/README.md)
for the step-by-step setup guide.

**Quick install:** open PowerShell on Windows 10/11 and paste:

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/sagar88776h/Suzi-my-personal-ai-assistant/refs/heads/claude/youthful-sagan-m97rqy/install.ps1 | iex"
```
